## 🌟 Key Features

- 📱 **Fully Responsive:** Optimized for desktops, tablets, and mobile devices.
- ⚡ **Fast & Lightweight:** Built using pure HTML5, CSS3, and JavaScript without bloated frameworks.
- 🎨 **Modern UI/UX:** Clean layout, dynamic animations, and readable typography.
- 💼 **Project Showcase:** Highlights key projects with links to code and live demos.
- 📬 **Contact Form:** Easy way for recruiters and visitors to reach out.
